# 自编公开示例

`documents/` 中两份短资料描述虚构的“星河项目”，不来自私人语料。
`evaluation.json` 给出四个问题及应人工核对的证据原句，适合检查首次问答和引用跳转。
它不是已完成的检索标注，也不是质量基准报告。

在全新克隆中，按根目录 README 安装依赖、准备模型、复制 `.env.example`、将这两份资料复制到 `data/raw/` 后入库。
选中检索结果的真实 `chunk_id`，通过评估页或 CLI 保存标注，再比较同一语料、同一标注下的快照。
文档 ID 与源路径有关，不预置跨机器失效的切片编号。

截图建议由维护者手动启动并导入这两份资料后截取：问答与证据、知识库任务、设置分节反馈。
裁去 API 密钥、账号、真实来源路径和私人资料；当前仓库不附未经脱敏核对的截图。
